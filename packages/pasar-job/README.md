# pasar-job

Job-side helpers for [pasar](https://github.com/fanpu/pasar). No dependencies; every call is a
no-op when the script isn't running under pasar.

    uv pip install "pasar-job @ git+https://github.com/fanpu/pasar#subdirectory=packages/pasar-job"

See pasar's `docs/jobs.md` for the full guide.
